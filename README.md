# PATENTMIND

R&D 엔지니어를 위한 AI 특허 스크리닝 플랫폼 **PatentMind AI**의 프런트엔드 MVP(목업)입니다.

기획 배경, 4단계 스마트 선별 엔진, 정량/정성 평가 기준 등 제품 기획 전체 내용은 별도 기획서 문서를 참고하세요.

## 기술 스택

- Vue 3 (`<script setup>`) + Vite
- Vue Router, Pinia
- lucide-vue-next (아이콘)
- axios (API 클라이언트, 현재는 목업 데이터로 폴백)

## 실행 방법

```bash
npm install
npm run dev
```

기본적으로 `VITE_API_MOCK` 환경변수가 `false`가 아니면 모든 API 호출이 실제 백엔드 대신 `src/mocks/index.js`의 목업 데이터로 응답합니다.

## 현재 구현 범위 (MVP)

- 로그인(목업) → 대시보드 → 특허 검색 → 처리중 → 결과(4-Tier) → 상세 분석 → 트렌드 → 내 작업공간 → 관리자 콘솔
- 검색 조건: 출원 기간(3/5/10년/직접설정), 소멸·포기 특허 제외, IP5 국가 다중 선택, AI 키워드 확장(동의어·IPC/CPC 추천)
- 정량 평가: 패밀리 크기·피인용 횟수·청구항 수/범위·분쟁 이력·권리 유효성 5개 지표, 100점 만점
- 정성 평가: 로드맵·스펙 중첩도, 회피설계 난이도 (상/중/하)
- 4단계 등급 매트릭스: Core(🔴) / Major(🟡) / Reference(🟢) / Noise(⚪)
- 관리자 콘솔: 외부 데이터 동기화 로그 조회 (KIPRIS / Google Patents / USPTO)

## 의도적으로 MVP에서 제외한 기능

- 정량 스코어링 가중치의 수동 조정 UI (표준화된 고정 알고리즘 유지 원칙)
- AI가 청구항 회피 대안 설계를 자동 생성하는 기능 (신뢰성·법적 리스크로 제외, "회피설계 난이도" 지표만 제공)
- 사내 IP팀 / 연구소장·PM 전용 화면 (Phase 3 로드맵으로 유지)

자세한 근거는 기획서 v1.4의 "MVP 범위 확정 및 제외 기능" 절 참고.
